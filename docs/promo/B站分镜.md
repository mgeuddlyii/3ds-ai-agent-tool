## 4. 素材从哪来（三条路，建议 A+B 混）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. 模拟器逐帧**（我能全包） | 脚本跑一遍，按固定间隔截图 → 合成视频 | 画面干净、可复现、我能直接产出 | 没有真机质感；没有按键手感 |
| **B. 手机拍实机**（你拍） | 手机架在支架上拍 3DS 屏幕 | 有真实感，B站观众爱看 | 手抖、反光、对焦要试 |
| **C. 采集卡** | 有卡就最省事 | 画质最好 | 你手上大概没有 |

**建议**：S4、S6、S7（确认屏 / 数字 / 目录）用 **A 的干净画面**（信息要看得清）；
S1、S2、S5 用 **B 的手机实拍**（要真实的手感）。两者交替，观感不闷。

> 我能做的部分：A 方案的全部（逐帧 PNG 序列 + 转视频）。
> 本机目前没有 ffmpeg，我可以试 `pip install imageio-ffmpeg`（自带二进制，pypi 是通的），
> 装不上就给你 PNG 序列 + 一页合成说明。

## 5. 录制时的坑（先记着，少返工）

1. **先把 config 的 `ui.font_size` 还原成 `mid`** —— 上次留成 `large`，截图里下屏文字叠成一团。
2. **确认屏会停在结果页等 B**，不会自动跳回；别以为程序挂了。
3. 下载 5.4MB 在模拟器里要几十秒，**录的时候别剪掉进度太长**，1.5× 加速即可。
4. `action.log` 那行 ALLOW 在 `sdmc:/3ds/aiconsole/action.log`，录的时候别让文件名被裁。
5. 录 S9 断网前，**先确认离线攻略模型在卡上**（`app/data` 里的 guide_kb），别录到"模型缺失"的报错。
