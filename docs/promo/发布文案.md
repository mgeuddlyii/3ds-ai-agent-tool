## 二、GitHub Release（v0.99.8）

### 中文

```markdown
## 0.99.8 —— 它开始自己动手了

这一版的主线只有一件事：**把"下命令 → 它执行"这条路打通，并且每一步都有证据。**

### 新增
- **AI 可以自己下载文件**：`file.fetch url=… [sha256=…]`
  下载到 `pkgs/`，先写 `.partial` 再改名——断线不会留下"看起来完整"的半个文件。
- **下载并安装合成一步**：`install=1`
  一次确认，下载 → 校验摘要 → 装进 `3ds/`。摘要用刚下下来的那份比对，
  "下的就是装的"；装失败会明说是哪一步失败、文件在哪。
- **AI 主动提问**：模型可以给你 2~4 个选项，下屏自动切到选项页，
  选中只填进输入框（不替你发送）。
- **复制代码**：「选项」面板新增一行，把回复里最近一段代码取回输入框。
- **字号可调**：设置里的「字号」真的生效了（标准 / 大）。

### 修
- 双重确认动作（清空回收站）键盘无法确认的死锁。
- 动作参数解析里 72 字节的隐形上限——长 URL 会被静默丢弃，现已修复。
- 中英界面下若干排版溢出。

### 已知问题
- **语音输入当前不可用**：所用云端免费 ASR 已全部下线/收费。
- 说明书（HOME 菜单里的「?」）仍是占位。

### 安全边界（没变）
四道闸：模型只给数据 / 编译期白名单 / 物理确认 / 路径不来自 AI。
下载只落地 `pkgs/`，文件名由 URL 推出，模型指定不了路径；单文件上限 16MB。
```

### English

```markdown
## 0.99.8 — It does the work now

The whole point of this release: **make "ask → it executes" real, with evidence at every step.**

### Added
- **The AI can fetch files itself** — `file.fetch url=… [sha256=…]`
  Downloads into `pkgs/`, writing to `.partial` first: an interrupted transfer can never
  leave a file that *looks* complete.
- **Fetch + install in one step** — `install=1`
  One confirmation covers both: download → verify SHA-256 → install into `3ds/`.
  The hash is checked against what was actually downloaded, not what the model claimed.
- **The AI can ask you questions** — 2–4 options, rendered on the bottom screen.
  Picking one only fills the input box; it never sends on your behalf.
- **Copy code** — a new row in the Options panel copies the latest fenced block to the input box.
- **Font size actually works** now (Standard / Large).

### Fixed
- Double-confirm actions (empty trash) could never be confirmed with the keyboard.
- A hidden 72-byte limit in action-argument parsing silently dropped long URLs.
- Several text overflows in the English UI.

### Known issues
- **Voice input is currently unavailable** — the free cloud ASR endpoints it relied on are gone.
- The HOME-menu manual is still a placeholder.

### Safety model (unchanged)
Four gates: model only supplies data / compile-time whitelist / physical confirmation /
paths never come from the model. Downloads land only in `pkgs/`, the filename is derived
from the URL (the model cannot choose a path), and a single file is capped at 16 MB.
```

## 七、GBAtemp（英文，3DS 区）

**标题**：`[Release] AIConsole — an AI agent for 3DS that actually executes tasks (fetch + install, with confirmation gates)`

```markdown
Most "AI on a console" projects are a chat window. This one executes.

You say "download and install that", it shows you a confirmation screen with the URL and
the expected hash, and only after you approve does it fetch the file, verify the SHA-256,
and install it into `3ds/`. Everything runs on the console — no PC relay, no middleman
server; requests go straight to the provider with your own API key.

**What it can do today**
- Fetch a file from a URL into `pkgs/` (`.partial` → rename, so an interrupted download
  can never leave something that looks complete)
- Fetch + install in one confirmation (SHA-256 checked against what was actually downloaded)
- Create/rename/delete files in its own sandbox, switch app region/language, change settings
- Offline guide model: 211 games, 1.18 MB, works with **no API key and no network**

**Safety model** — four gates: the model only supplies data; actions come from a
compile-time whitelist; you physically confirm each one; paths are never taken from the model.
Downloads are capped at 16 MB and can only land in `pkgs/`.

**Install** — drop `AIConsole.3dsx` into `sdmc:/3ds/`, run from the Homebrew Launcher.

Tested on New 3DS. Old 3DS performance is untested — reports welcome.

**Known issues** — voice input is currently broken (the free ASR endpoints it used are gone);
the HOME-menu manual is a placeholder.

MIT licensed. Source + releases: https://github.com/mgeuddlyii/3ds-ai-agent-tool
```
