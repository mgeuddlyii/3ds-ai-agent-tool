## 二、GitHub Release

### 中文

```markdown
## 0.99.8

这版没加什么花活，主要把"下命令 → 它真的执行"这条路补完整了。

**能自己下载了**
`file.fetch url=…`，文件落到 pkgs/。先写 .partial 再改名，中途断了不会给你留一个
看起来完整的半截文件。

**下完能直接装**
加 `install=1`，一次确认走完：下载 → 校验 sha256 → 装进 3ds/。
校验用的是刚下下来那份的摘要，不是模型嘴上说的那个。装失败会告诉你卡在哪、
文件还在 pkgs/ 里。

**它会反问你了**
模型可以给 2~4 个选项，下屏直接切到选项页。选中只是填进输入框，不会替你按发送。

**复制代码**
「选项」面板多了一行，把回复里最近那段代码捞回输入框。3DS 没有剪贴板，
输入框是最接近的东西。

**字号真的能调了**
以前设置里那项只是存着，改了没反应。现在标准 / 两倍。只做整数倍，
150% 试过，字会糊。

### 修的
- 清空回收站要按两次确认，键盘死活确认不了，只能摸屏幕。修了。
- 动作参数解析里有个 72 字节的隐形上限，长 URL 会被默默丢掉，报错还写着
  "只接受 http/https"，看着像没填地址。修了。
- 英文界面几处文字出血。

### 还坏的
- **语音输入用不了**。原来那几个免费 ASR 接口全挂了/收费了，我还没换成别的。
- HOME 菜单里那个说明书是占位文件，点开是空的。

### 安全这块
四道闸没动过：模型只给数据、动作走编译期白名单、每一步你亲手点、路径不由模型决定。
下载只能落 pkgs/，文件名从 URL 推出来，单文件 16MB 封顶。
```

### English

```markdown
## 0.99.8

No new bells. Mostly closing the loop on "ask it to do something, and it actually does it".

**It can fetch files**
`file.fetch url=…` pulls a file into `pkgs/`. Writes to `.partial` first, so an interrupted
download never leaves you with half a file that looks whole.

**Fetch and install in one go**
`install=1`: one confirmation covers both. Download → check sha256 → install into `3ds/`.
The hash comes from what was actually downloaded, not from what the model said it would be.
If the install fails you get told where it stopped, and the file is still in `pkgs/`.

**It can ask you things**
2–4 options, drawn on the bottom screen. Picking one fills the input box. It won't send for you.

**Copy code**
New row in the Options panel. Copies the last fenced block back into the input box.
The 3DS has no clipboard; the input box is the closest thing.

**Font size works now**
It used to be a setting that did nothing. Standard / 2x. Integers only — I tried 150%,
the text turns to mush.

### Fixed
- Double-confirming "empty trash" never worked with buttons, only by tapping the screen.
- A hidden 72-byte cap in argument parsing ate long URLs, then reported
  "only http/https accepted", which looks like you forgot the address.
- A few text overflows in the English UI.

### Still broken
- **Voice input.** The free ASR endpoints it used are gone or paid now. Not replaced yet.
- The HOME menu manual is a placeholder file. It opens empty.

### Safety
Unchanged. Four gates: the model supplies data only, actions come from a compile-time
whitelist, you tap approve on every one, paths never come from the model.
Downloads land in `pkgs/` only, filename derived from the URL, 16 MB per file.
```

## 七、GBAtemp

标题：`[Release] AIConsole 0.99.8 — an AI agent on 3DS that fetches and installs, with a confirmation screen`

```markdown
Most "AI on a console" projects are a chat window. This one runs tasks.

Ask it to install something and it shows you a confirmation screen with the URL and the
expected hash first. Approve, and it fetches the file, checks the sha256 against what it
actually downloaded, and installs it into `3ds/`. All on the console — no PC relay, no
middleman server; requests go straight to the provider with your own API key.

What it does right now:
- fetch a URL into `pkgs/` (writes `.partial` first — an interrupted download can't leave
  a file that looks complete)
- fetch + install behind one confirmation
- create / rename / delete files in its own sandbox, change a title's region and language
- offline guide model: 211 games, 1.18 MB, no key and no network needed

The model never gets to choose a path. Actions come from a compile-time whitelist, and you
approve each one. Downloads cap at 16 MB and only land in `pkgs/`.

Install: drop `AIConsole.3dsx` into `sdmc:/3ds/` and run it from the Homebrew Launcher.

Tested on New 3DS. I have no Old 3DS to try it on — if you do, I'd like to know.

Known issues: voice input is dead (the free ASR endpoints it used are gone), and the HOME
menu manual is a placeholder.

MIT. https://github.com/mgeuddlyii/3ds-ai-agent-tool
```
