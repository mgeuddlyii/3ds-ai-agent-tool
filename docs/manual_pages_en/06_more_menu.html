More Menu

6 entries, ordered by how often they are used.

  1. Translate: turns on chat translate mode; a mode, not a new screen.
  2. Providers: lists all providers; switch and set credentials on demand.
  3. Region set: lists games with a region language set; revoke one by one. Lands in sdmc:/luma/titles/gameID/locale.txt.
  4. Update: model, guide DB, hardware KB - install or roll back item by item.
  5. PC files: copy games and files from a PC to the SD card, with a list and staged progress.
  6. Plugins: manage 3gx under luma/plugins; view and toggle, cannot delete.

Why Region set exists

Asking the AI in chat to set a region is fine, but viewing and revoking afterwards happens here. Without it you could not see on the 3DS which files you changed.
