Quick Start

Before you begin

  1. A hacked 3DS (Luma3DS + boot9strap) with a writable SD card.
  2. One credential, pick one of three: key file / Doubao scan / on-screen entry.
  3. Launch from the Homebrew Launcher, or tap the HOME icon.

Three credentials

  • Key file: the key goes in SD:/3ds/aiconsole/key.txt, read at startup.
  • Doubao scan: More - Providers - Doubao, no key needed.
  • On-screen entry: Providers - entry screen, type key / model name / URL.

The default provider is deepseek. Offline guides work without any credential.

First chat

  1. On Home pick Chat, press A.
  2. Press Y for the keyboard, or hold ZL and speak.
  3. Replies show on the top screen; B returns to Home, history is kept.
