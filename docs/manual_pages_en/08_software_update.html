Software Update

Update packs

  • Put them in SD:/3ds/aiconsole/update/; the app scans manifest.json.
  • Each artifact is checked by size plus sha256; mismatches are not installed.
  • Versions only go up; same as current shows the already-latest message.

Install

  • .3dsx overwrites straight into SD:/3ds/AIConsole.3dsx.
  • .cia only copies into the cias/ folder and tells you to tap it in FBI. Homebrew has no AM service rights, so it cannot self-install CIA.

Confirm

The update screen lists all facts on top; only allow / deny below. Nothing installs unless you press. An interrupt cannot corrupt the original: verify first, install after.

Release notes show in the built-in HTML viewer.
