Credentials

Three ways; Home tells you automatically whether one is set.

Way 1: key file

  • The key goes in SD:/3ds/aiconsole/key.txt.
  • Plain text, one per line, read at startup.
  • Fits any provider that takes an API key.

Way 2: Doubao scan

  • More - Providers - Doubao; scan to bind the machine to your account.
  • No key needed.

Way 3: on-screen entry

  • Providers - entry screen: type key / model name / URL / thinking level.
  • Change config without a PC.

Multiple keys

The key manager can switch, delete, and import (Y to import).

Priority

An active key in the keystore beats key.txt; key.txt beats the built-in config. The default provider is deepseek; switch via Providers.
