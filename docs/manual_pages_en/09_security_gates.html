Safety: Four Gates

The action layer is bound by four gates; none can be missing.

  1. The model only gives data: its output is an action request, not an instruction; it never sees your file contents.
  2. Compile-time allowlist: only 4 actions can run, hardcoded; nothing can register a new action at runtime.
  3. Physical confirm: every action pops a confirm screen; without allow it does not run.
  4. Paths never come from the AI: every landing path is a local constant; the model naming a path has no effect.

Action allowlist

  • Write file: create or overwrite one text file, lands in sdmc:/3ds/aiconsole/out/.
  • Install app: .3dsx moves straight to sdmc:/3ds/; .cia tells you to go to FBI.
  • Set region: sets a game's region language, lands in sdmc:/luma/titles/gameID/locale.txt.
  • Clear region: undoes the above.

If the model tries anything outside the allowlist, the same confirm screen pops up and it is audited - but the action layer does not accept it; pressing allow does nothing.
