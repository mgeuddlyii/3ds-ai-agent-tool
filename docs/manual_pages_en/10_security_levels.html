Safety: Levels and Logs

Safety levels

  • L0 Chat (default): chat only, no actions run.
  • L1 Files: adds write file.
  • L2 System: adds install app, set/clear region.
  • Higher levels (L3 Low-level, L4 Full system, L5 Highest): full-system capability is out of reach in this build; everything stays in user mode.

Default is L0, not kept after exit. Every launch starts at the lowest level. Home shows this session's level.

What it cannot do

Write NAND, flash FIRM. Not unguarded - the capability does not exist. Nobody, including the model, can do these through this app.

Two files

  • action.log: every allow or deny is appended to SD:/3ds/aiconsole/action.log, with timestamp and details.
  • status.txt: the run log lives in SD:/3ds/aiconsole/status.txt; follow on-screen hints when something breaks.
