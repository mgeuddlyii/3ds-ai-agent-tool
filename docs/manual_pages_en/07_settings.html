Settings

Five groups, plus the safety level.

UI

  • Theme: Day / Night.
  • Stereo depth: not enabled in this build; adjusting has no effect yet.
  • Language.

AI

  • Default provider, model, reply length (short / standard / long).
  • Context turns, memory (can be cleared).

Reminders

  • NAND backup reminder toggle, update auto-check toggle.

Gates

  • Confirm before delete, confirm before batch actions.
  • Single-write size cap, batch file-count cap.

Diagnostics

  • Layout overflow flags, notes display, verbose status output.

Safety level

Defaults to L0 Chat and is not kept after exit. Every launch starts at the lowest level; raise it manually. See the two safety pages.
