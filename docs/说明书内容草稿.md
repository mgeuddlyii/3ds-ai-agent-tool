## 1. 这是什么

AIConsole 是跑在 3DS 上的 AI 控制台，同时是一个 AI 游戏助手。
它做三件事：

1. **对话**：把你说的话或打的字送给云端大模型，回复显示在上屏。
2. **执行**：模型可以在安全闸门内替你做 4 类固定动作
   （写文件、装程序、设/撤游戏区域），每一步都要你亲自确认。
3. **离线攻略**：不联网、不用 Key，直接检索内置的 211 款游戏 FAQ。

它不是聊天玩具——**重点是会动手的执行层**。
模型看不到你的文件内容，只能按白名单动作申请操作；
所有路径由本地复核，不听模型指路。

**运行形态**：`.3dsx`（从 Homebrew Launcher 启动）或 `.cia`
（用 FBI 装进主菜单，和正版软件一样从图标启动）。

**机型**：New 3DS / New 3DS LL 功能完整；Old 3DS 可运行，
但立体 3D 与眼动追踪不可用。

**首次启动**有 4 页不可跳过的引导：选界面语言（选错整屏提示都看不懂，
所以放最前）→ 能力边界（它能做什么/不能做什么）→ NAND 备份提醒
（不强制，但持续可见）→ AI 服务说明（本应用不自建服务端，
没有设备码登录，稍后填 Key 即可）。

【拆屏建议】1 屏：三句话 + 形态 + 机型 + 首启引导预告。

## 2. 快速上手

**开始之前**（三样东西）：

1. 一台已破解的 3DS（Luma3DS + boot9strap），SD 卡可写。
2. 一份凭据，三选一：
   - **API Key 文件**：把 Key 写进 `SD:/3ds/aiconsole/key.txt`
     （纯文本，一行一把，程序启动时自动读取）；
   - **豆包扫码**：不用 Key，「更多 → 服务目录 → 豆包」扫码登录；
   - **屏上录入**：「更多 → 服务目录 → 录入屏」直接敲
     Key / 模型名 / 网址 / 思考强度。
3. 从 Homebrew Launcher 启动 AIConsole，或从主菜单点图标。

默认服务商是 deepseek。不配任何凭据也能用「离线攻略」
（不联网、不用 Key），对话功能需要凭据。

**第一次对话**（30 秒）：

1. 主界面选「开始对话」，按 A。
2. 按 **Y** 打开系统键盘打字，或**按住 ZL** 直接说话。
3. 发送后回复显示在上屏；中途按 B 可返回主界面，记录不丢。

【拆屏建议】1 屏。凭据三选一要显眼——这是新手 90% 卡住的地方。

## 4. 对话

- 上屏是对话记录，下屏是输入与发送。
- **按 Y** 打开系统软键盘输入；**按 SELECT** 填入预设短语。
- **按住 ZL 说话**，松开结束采集。录音不足 0.5 秒会提示
  「录音不足 0.5 秒 · 按住 ZL 后再说」。
- 回复流式显示。中途按 B 返回主界面，记录不丢。
- AI 的回复可能夹带**动作标记**（如写一个文件、装一个程序）。
  这时会弹出**动作确认屏**：上屏是动作的完整事实，下屏只有
  「允许」「拒绝」两个选项。不按确认，什么都不执行。
- 要翻译回复：进对话前在「更多」第一项打开翻译模式
  （那是对话屏的一个模式，不是新屏）。

**常见状态**（屏幕原话，照抄即可对照）：

| 屏幕显示 | 含义 |
|---|---|
| `识别结果为空 · 建议放慢语速重试` | 采到音频但没识别出字 |
| `未采集到音频 · 确认麦克风未被占用` | 没采到声音 |
| `连接失败 · 原因见上屏` | 网络或服务商问题 |
| `Key 被拒绝（401）· 原因见上屏` | Key 无效或过期 |

【拆屏建议】2 屏：① 基本操作 ② 动作确认 + 状态对照表。

## 5. 配凭据（三种方式）

程序支持三种凭据，主界面会自动判断「配好没有」：

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **API Key 文件** | 把 Key 写进 `SD:/3ds/aiconsole/key.txt` | 任何支持 API Key 的服务商 |
| **豆包扫码** | 更多 → 服务目录 → 豆包 → 扫码 | 不想管 Key |
| **屏上录入** | 服务目录 → 录入屏，敲 Key / 模型名 / 网址 / 思考强度 | 改配置不用连电脑 |

- Key 文件是纯文本，一行一把；启动时自动读取，不需要在程序里导入。
- 多把 Key 可以在「Key 管理」屏切换、删除、导入（按 Y 导入）。
- 首次引导的第 4 页就是 AI 服务说明，末尾可跳去录凭据。
- 凭据优先级：Key 仓库里激活的 Key > `key.txt` 文件 > 内置配置。
- 默认服务商是 deepseek；换服务商走「服务目录」。
- 服务商不是全都能连：本机实测 `api.siliconflow.cn` 通，
  `api.openai.com` 超时。连不上时屏幕会给出原因，以屏幕为准。

【拆屏建议】2 屏：① 三种方式对比表 ② Key 文件格式 + 优先级。

## 6. 离线攻略

不联网、不用 Key 的内置攻略检索：

- 覆盖 **211 款游戏** 的 FAQ 与流程段落，原文直出，不编答案。
- 检索用内置微模型（1.18M 参数）+ BM25，全程在卡上跑。
- 进「离线攻略」屏，按 Y 打开键盘输入问题，检索结果直接显示。
- 限定游戏范围可缩小检索面（在屏内选择）。
- 状态说明：`词表加载失败 · 检索不可用` 表示内置词表没加载上，
  重启程序重试；仍不行看 `SD:/3ds/aiconsole/status.txt` 里的诊断行。

【拆屏建议】1 屏。

## 7. 更多菜单（6 项）

「更多」承接不常用但重要的入口，顺序按使用频率排：

| 顺序 | 入口 | 干什么 |
|---|---|---|
| 1 | 翻译 | 打开对话屏的翻译模式（是模式，不是新屏） |
| 2 | 服务目录 | 列全部服务商，切换 + 按需配凭据 |
| 3 | 已设区域 | 列出给哪些游戏设过区域语言，可逐个撤销。落点 `sdmc:/luma/titles/<游戏ID>/locale.txt` |
| 4 | 内容更新 | 模型 / 攻略库 / 硬件知识库，逐条独立安装或回滚 |
| 5 | 从电脑取文件 | 从电脑传输游戏与文件到 SD 卡，带清单和分段进度 |
| 6 | 插件 | 管理 `luma/plugins` 下的 3gx 插件：能看、能开关，不能删 |

「已设区域」是反悔用的——没有它，你在 3DS 上看不到自己动过哪些文件。
对话里让 AI 设区域同样可以，但事后查看与撤销都在这一屏。

【拆屏建议】1 屏，表格照搬。

## 8. 设置

设置分五组，另有安全等级：

1. **界面**：主题（白昼 / 黑夜）、立体深度（当前版本未启用立体渲染，
   调了暂时没效果）、语言。
2. **AI**：默认服务商、模型、回复长度（短 / 标准 / 长）、
   上下文轮数、记忆（助手的长期记忆，可清空）。
3. **提醒**：NAND 备份提醒开关、更新自动检查开关。
4. **闸门**：删除前确认、批量操作前确认、单次写入大小上限、
   批量文件数上限。
5. **诊断**：布局溢出提示、备注显示、详细状态输出。
6. **安全等级**：见 §10。**默认 L0 对话级，且退出后不保留**——
   每次启动都从最低等级开始，要用高级等级得手动调。

主界面显示的是「本会话」安全等级，以当前设置为准。

【拆屏建议】2 屏：① 五组速览 ② 安全等级（并入 §10）。

## 9. 软件更新

- 更新包放在 `SD:/3ds/aiconsole/update/`，程序扫描 `manifest.json`。
- 逐产物校验 size + sha256，对不上不装。
- `.3dsx` 直接覆盖安装到 `SD:/3ds/AIConsole.3dsx`；
  `.cia` 只复制到 `cias/` 文件夹，并提示去 FBI 里点一下
  （自制程序没有 AM 服务权限，不能自装 CIA）。
- 版本只升不降：包里版本和当前一样会提示「已经是最新」。
- 更新屏上屏列全部事实，下屏只有「允许」「拒绝」。不按不装。
- 更新说明页用内置 HTML 查看器显示（能力边界见 §14）。

【拆屏建议】1 屏。

## 10. 安全说明（重要）

AIConsole 的执行层靠四道闸门约束，缺一不可：

1. **模型只给数据**：模型输出的是动作申请，不是指令；
   它拿不到你的文件内容。
2. **编译期白名单**：可执行动作只有 4 个，写死在代码里，
   运行时报什么都注册不了新动作。
3. **物理确认**：每个动作弹确认屏，你不按「允许」就不执行。
4. **路径不来自 AI**：所有落点路径由本地常量决定，
   模型说「写到某某路径」无效。

**动作白名单**（全部，就这四个）：

| 动作 | 干什么 | 落点 |
|---|---|---|
| 写文件 | 建/覆盖一个文本文件 | `sdmc:/3ds/aiconsole/out/` |
| 装程序 | `.3dsx` 直接搬；`.cia` 提示去 FBI | `.3dsx`→`sdmc:/3ds/`，`.cia`→主菜单 |
| 设区域 | 给某个游戏设区域语言 | `sdmc:/luma/titles/<游戏ID>/locale.txt` |
| 撤区域 | 撤销上面的设置 | 同上 |

模型试图做白名单外的事，会弹同一个确认屏并记审计日志，
但**执行层不认**——按了也什么都不会发生。

**安全等级**（设置内调整，主界面显示本会话等级）：

| 等级 | 允许的范围 |
|---|---|
| L0 对话级（默认） | 只对话，不执行任何动作 |
| L1 文件级 | 加「写文件」 |
| L2 系统级 | 加「装程序」「设/撤区域」 |
| 更高等级 | 完整系统级能力**当前版本做不到**（全程用户态） |

**做不到的事**（不是没防，是根本没有这个能力）：
写 NAND、刷 FIRM。任何人（包括模型）借这个程序都做不到。

**审计**：每次允许/拒绝都追加写进
`SD:/3ds/aiconsole/action.log`（含时间戳与详情），可随时查。
**诊断**：程序运行日志在 `SD:/3ds/aiconsole/status.txt`，
出问题时按屏幕提示来这里看。两个文件不是一回事。

【拆屏建议】2 屏：① 四道闸 + 白名单表 ② 等级表 + 做不到清单 +
审计/诊断文件说明。这是说明书里最该被读完的一节。

## 12. 常见问题（FAQ）

**Q：识别结果为空？**
放慢语速重试；确认麦克风没被别的程序占用。
录音太短会提示「录音不足 0.5 秒 · 按住 ZL 后再说」。

**Q：Key 被拒绝（401）？**
Key 无效、过期或额度用尽。换一把，或在 Key 管理屏切换。

**Q：连接失败？**
先看屏幕上屏给的原因。3DS 的 TLS 较老，部分现代服务商
可能握手失败；换 `api.siliconflow.cn` 这类实测可用的服务商。

**Q：攻略检索 0 命中？**
换更短的关键词；确认限定游戏范围没选错。
显示 `词表加载失败 · 检索不可用` 时重启程序重试。

**Q：CIA 装不上，报 `0xD8E08027`？**
标题版本比机器上已装的旧。卸载旧版或用 FBI 直接覆盖，
保持版本号只升不降。

**Q：麦克风不可用？**
屏幕会提示「麦克风不可用 · 诊断见 status.txt」，
照 status.txt 里的诊断行处理。

**Q：为什么没有立体 3D？**
Old 3DS 不支持；New 3DS 在设置里开（当前版本立体渲染未启用，
开关预留）。

**Q：怎么把电脑上的游戏搬上卡？**
主界面没有直达入口——「更多 → 从电脑取文件」，那是唯一入口。

**Q：模型让我做危险操作怎么办？**
白名单外的事执行层不认。确认屏上会写完整事实，不确定就拒绝。

**Q：更新装了一半不动了？**
更新屏有分段进度；中断不会写坏原文件（先校验后安装）。

**Q：说明书里为什么没有图片？**
内置查看器是 HTML 子集，不支持图片（见 §14）。
配图在仓库文档里，App 内展示要等单独的贴图机制。

【拆屏建议】2-3 屏，按主题分组。

## 14. App 内说明书的形态边界（实施前必读）

这一节不是给终端用户看的，是给将来做路线 B 的人看的——
**内置查看器（`sc_viewer.c` + `gfx/html.c`）的能力边界**：

| 能力 | 现状 |
|---|---|
| 标题 | ✅ h1 / h2 / h3 三级 |
| 段落 | ✅ p / div，自动换行 |
| 列表 | ✅ li（支持 ul/ol 嵌套缩进） |
| 引用 | ✅ blockquote（缩进 + 弱化色） |
| 行内加粗/斜体 | ❌ 不支持（没有 b/i/strong/em 的行内样式） |
| 图片 | ❌ 不支持（没有 img 标签、没有贴图渲染） |
| 超链接/JS/CSS | ❌ 不支持 |
| 屏幕 | 3DS 双屏 320×240 级别，一屏约 13 行文字 |

推论（都已写进页面包 `docs/manual_pages/`）：
