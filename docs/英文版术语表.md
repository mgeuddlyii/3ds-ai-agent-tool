## 红线（写译文时反复确认的三条）

1. **动作协议名永不翻译**：`file.write`、`fs.read`、`app.open` 等在译文里必须
   保持原样，包括出现在句子中间时。例：
   - `已执行「创建文件」` → `Done: create file`（引号里的中文是**说明**，
     可以译；但如果字符串里直接出现 `file.write` 这样的 token，一个字都不能动）
2. **格式占位符必须一一对应**：`%s` / `%d` / `%ld` / `%.*s` 的**个数与顺序**不变。
   少一个或改顺序 → 3DS 上直接显示乱码甚至崩。i18n_table.py 已在编译期校验，
   但校验的是"表里有译文"，占位符一致性还要 `check_i18n.py` 单独查。
3. **英文比中文长**：同一个界面宽度下中文一行能放 40 字，英文只能放 20 出头。
   所以译文不要写长句，能断成两句就断。给按钮的中文是两个字（如"发送"），
   英文 `Send` 正好；`[R] 改短语` 译成 `[R] Edit phrases` 就要看会不会撞宽度 ——
   这一条交给 `check_i18n.py` 的宽度判据查，不靠肉眼。
