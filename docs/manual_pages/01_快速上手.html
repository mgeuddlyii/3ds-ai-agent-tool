快速上手

开始之前

  1. 一台已破解的 3DS（Luma3DS + boot9strap），SD 卡可写。
  2. 一份凭据，三选一：Key 文件 / 豆包扫码 / 屏上录入。
  3. 从 Homebrew Launcher 启动，或从主菜单点图标。

三种凭据

  • Key 文件：Key 写进 SD:/3ds/aiconsole/key.txt，启动自动读取。
  • 豆包扫码：更多 - 服务目录 - 豆包，不用 Key。
  • 屏上录入：服务目录 - 录入屏，直接敲 Key / 模型名 / 网址。

默认服务商是 deepseek。不配凭据也能用离线攻略。

第一次对话

  1. 主界面选「开始对话」，按 A。
  2. 按 Y 打开键盘打字，或按住 ZL 直接说话。
  3. 回复显示在上屏；按 B 返回主界面，记录不丢。
