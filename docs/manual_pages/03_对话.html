对话

基本操作

  • 上屏是对话记录，下屏是输入与发送。
  • 按 Y 打开系统软键盘输入。
  • 按 SELECT 填入预设短语。
  • 按住 ZL 说话，松开结束采集。
  • 录音不足 0.5 秒会提示：录音不足 0.5 秒，按住 ZL 后再说。
  • 中途按 B 返回主界面，记录不丢。

动作确认

AI 回复可能夹带动作标记。这时弹出确认屏：上屏是完整事实，下屏只有允许、拒绝。不按确认，什么都不执行。

翻译模式

进对话前在「更多」第一项打开，回复转为中文。是对话屏的模式，不是新屏。

常见状态

  • 识别结果为空：放慢语速重试。
  • 未采集到音频：确认麦克风未被占用。
  • 连接失败：原因见上屏。
  • Key 被拒绝（401）：Key 无效或过期，换一把。
