常见问题（一）

识别结果为空？

放慢语速重试，确认麦克风没被别的程序占用。录音太短会提示按住 ZL 后再说。

Key 被拒绝（401）？

Key 无效、过期或额度用尽。换一把，或在 Key 管理屏切换。

连接失败？

先看屏幕上屏给的原因。3DS 的 TLS 较老，部分现代服务商可能握手失败，换实测可用的服务商。

攻略检索 0 命中？

换更短的关键词，确认限定游戏范围没选错。显示词表加载失败时重启程序重试。

CIA 装不上，报 0xD8E08027？

标题版本比机器上已装的旧。卸载旧版或用 FBI 直接覆盖，版本号只升不降。

麦克风不可用？

屏幕提示诊断见 status.txt，照里面的诊断行处理。
