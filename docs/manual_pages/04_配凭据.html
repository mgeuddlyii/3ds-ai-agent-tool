配凭据

三种凭据，主界面会自动判断配好没有。

方式一：Key 文件

  • Key 写进 SD:/3ds/aiconsole/key.txt。
  • 纯文本，一行一把，启动时自动读取。
  • 适合任何支持 API Key 的服务商。

方式二：豆包扫码

  • 更多 - 服务目录 - 豆包，扫码把机器绑到账号。
  • 不用 Key。

方式三：屏上录入

  • 服务目录 - 录入屏，直接敲 Key / 模型名 / 网址 / 思考强度。
  • 改配置不用连电脑。

多把 Key

Key 管理屏可切换、删除、导入（按 Y 导入）。

优先级

Key 仓库激活的 Key 优先于 key.txt 文件，key.txt 优先于内置配置。默认服务商是 deepseek，换服务商走服务目录。
