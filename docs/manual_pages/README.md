## 写作约束（html.c 能力边界，改页面必须遵守）

- 只用 `h1` / `h2` / `h3` / `p` / `div` / `li` / `ul` / `ol` / `blockquote`。
- **不要**行内样式（b/i/strong/em 不渲染）、**不要** `img`
  （查看器无贴图机制）、**不要** JS/CSS/超链接。
- 每页控制在 13 行上下（3DS 屏一屏容量），超了拆页。
- 屏幕原话与母本保持一致（母本附录 A 有出处表）。

## 将来内嵌方式（实施期动作，现在不做）
